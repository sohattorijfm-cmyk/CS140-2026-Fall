Questions(Nov 25th)

Can you use Bootstrap on your final project?

NO

Which components did you add to your page, and which of them needed Bootstrap's JavaScript to work?

I added a Navbar, a Card (with a list group), and an Accordion. The Navbar's collapsible menu and dropdown, as well as the Accordion, require Bootstrap's JavaScript to work (using data-bs-toggle to control opening and closing). The Card works with Bootstrap's CSS alone.
