Box Model

block tags are like div, p, h1.

inline tags are like emb, a, strong.

Questions

Block tags start on a new line and take up the full width of their parent container, while inline tags flow within text without starting a new line and take up only as much width as their content needs

Margin: The outermost space outside the element's border, used to push other elements away and create distance between boxes.

Border: The line that wraps directly around the padding and content.

Padding: The inner space between the content and the border, used to give breathing room inside the box.

CSS units are generally divided into absolute and relative categories
