What is AJAX?

AJAX stands for Asynchronous JavaScript and XML. It is not a programming language; it is a set of web development techniques used to build faster and more interactive web applications

What are the two ways you can run JavaScript?

Separating HTML (structure) from JavaScript (behavior) keeps the code organized, making it easier to manage and modify. Furthermore, a single file can be reused across multiple pages, and the browser's caching mechanism helps speed up page loading.

How do you use the inspector (DevTools) to debug your JavaScript? How do you find the line number of an error?

You use browser DevTools to debug JavaScript by opening the panel (right-click Inspect or press F12 / Cmd+Option+I on Mac / Ctrl+Shift+I on Windows), checking the Console tab for error messages and console.log() output, inspecting the Network tab to verify requests (such as submit.json in your AJAX form), and setting breakpoints in the Sources tab to step through code.

How does your code prevent the form from being submitted? Why do we need to prevent it?

In JavaScript, you use the `event.preventDefault()` method to prevent the default form submission behavior (such as page reloading or sending data to a server). We prevent the default form submission primarily to stop the browser from automatically reloading or navigating away from the current page.
