1. The form tag has an "action" attribute. What does it do?

The tag specifies the URL or destination where the form data should be sent for processing when a user clicks the submit button

2. The form tag has a "method" attribute. What does it do?

the method attribute inside a form tag specifies how form data is sent to the server

3. What is the difference between a "POST" and a "GET"?

GET is used to request (retrieve) data from a server, while POST is used to send (submit) data to a server to create or update a resource
