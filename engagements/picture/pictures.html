Questions & Answers

  1. What kind of photos are good to encode using JPEG?

    Photos with continuous tones, rich gradients, complex colors, and fine details, such as real world photography.

  2. What kind of photos are good to encode using GIF?

    Simple graphics with limited flat colors (up to 256 colors), logos, simple icons, and simple frame-by-frame animations.

  3. What is unique about the PNG format?

    It features lossless compression and supports variable alpha-channel transparency, making it ideal for sharp graphics overlaid on different backgrounds.

  4. How do you resize your photo to the size it should be displayed?

    By editing the image file's pixel dimensions using photo editing software (such as Photoshop, Canva, or GIMP) before inserting it into the webpage.

  5. Why should you resize photos using photo editing software instead of resizing it using CSS?

    CSS only changes the visual scale, meaning the user still downloads the full-sized file. Resizing in image software reduces the actual file size, which optimizes page load speed and saves bandwidth.
