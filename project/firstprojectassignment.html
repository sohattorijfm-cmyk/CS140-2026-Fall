1.Internet

2.Web

3.How are the Internet and Web different?

4.ASCII and Unicode

ASCII is an old basic standard to show English alphabets or numbers. Unicode is todays world standard to show various language, not only limited English

5.What is UTF-8

It is a text encoding method to deal with different languages to be used around the world, such as English and Japanese.

6.URL

It is adress for information on the internet. It is made by scheme [https://], domain [.com], and path (/folder/page.html)

7.Domain Name

It is the unique name with worldwide on the internet to indicate where it is on the internet.

8.HTTP

Communication rules for exchanging information between a web server and a web browser on the Internet.

9.HTTPS

It encrypts communication between a web browser and a website for the secure exchange of data between them.

10.IP Adress

It is an assigned number for electric devices to connect to the internet, such as PC or smartphone.

11.DNS

It changes to IP sdress which computer uses to exchange from domain name which human can read easily.

12.W3C Recommendations

This is approved and opened by passing the official deliberation process as web standard from W3C.
